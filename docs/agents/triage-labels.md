# Local Work Statuses

The skills speak in terms of five canonical triage roles. In this repository, record the matching status in the front matter or status line of the local specification or ticket.

| Skill role | Local status | Meaning |
| --- | --- | --- |
| `needs-triage` | Needs triage | Maintainer needs to evaluate the work. |
| `needs-info` | Needs info | Waiting on information from the requester. |
| `ready-for-agent` | Ready for implementation | Fully specified work that an agent can implement. |
| `ready-for-human` | Ready for human | Work that requires human implementation. |
| `wontfix` | Won't fix | Work that will not be actioned. |

When a skill mentions a role, use the corresponding local status instead of a hosted tracker label.
